# Library Management System

A full-stack MERN application for library book cataloging and student book issue tracking.

## 🚀 Live Demo
**[https://library-management-system-zeta-three-66.vercel.app](https://library-management-system-zeta-three-66.vercel.app)**

## Features
- **Book Catalog**: Browse and search books by title, author, or ISBN.
- **Book Issue System**: Issue books with Student ID and Issue Date.
- **Authentication**: JWT-based authentication for Students and Librarians.
- **Database**: MongoDB cloud persistence.

## Tech Stack
- **Frontend**: React (Create React App)
- **Backend**: Node.js & Express
- **Database**: MongoDB Atlas
